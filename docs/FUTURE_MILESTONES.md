# Historical milestone proposals — not a live backlog

This list was drafted after the v1.0.3 task-system snapshot. It is retained as planning history, not as a statement of current work or a commitment for v1.1.0. Check [`AGENT_STATUS.md`](AGENT_STATUS.md), [`../PROJECT_PLAN.md`](../PROJECT_PLAN.md), and the live GitHub issues before proposing work. The current source is not the same as the latest published v1.0.5 app; source implementation alone does not make a feature part of a published release.

## Browser/search proposals — historical issue #167

[Issue #167](https://github.com/AbrarulHaque8541/ai-personal-task-assistant/issues/167), “Meta search engine with aggregated results + drag-reorder engine list,” is **closed**. Its historical ideas included a visual engine picker, quick engine-switch/re-search controls, customizable ordering, and client-side shortcuts without a remote aggregation backend.

Do not treat this section as an open v1.1 scope or claim every proposal shipped. If any part is reconsidered, inspect current source and the closed issue's final context, then create or use a current owner-approved issue.

## Task proposals — historical issue #168

Recurrence and task tags are implemented in current source and are documented in [`TASK_REMINDERS.md`](TASK_REMINDERS.md) and [`TASK_ADD_GAPS.md`](TASK_ADD_GAPS.md); they are not future work to duplicate. These later source changes are **not** included in the published v1.0.5 artifact, which predates the current application identity. For release availability, verify the live Releases page.
