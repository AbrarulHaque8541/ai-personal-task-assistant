Run `sh ./tools/run-core-tests.sh` from `android-app/`. It compiles the task logic, updater policy, strict release JSON parser, GitHub metadata client, and APK downloader with the local JDK only. Host fixtures drive fake HTTP connections through the production metadata and download code, including mid-transfer cancellation, simulated interrupted-transfer/restart cleanup, and an actual streamed body crossing the 100 MiB ceiling. Policy tests verify that hash/signer failures delete temporary files. A minimal `Context` stub exists only under `tools/host-stubs` and is never included in Android app sources. The suite uses no Android SDK, Gradle, network access, APK assembly, or external libraries.
